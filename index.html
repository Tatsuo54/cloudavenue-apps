Cloud Avenue｜Web Apps

ちょっとしたお役立ちアプリたち A collection of handy utility web apps

画像一括トリミングツール Batch Image Cropper
複数画像の上下左右を一括でトリミング。ピクセル・パーセント指定対応。 Batch crop multiple images from all sides. Supports pixel and percentage dimensions.
画像一括WebP変換ツール Batch WebP Converter
複数画像をWebP形式に一括変換。品質調整と圧縮率のプレビュー付き。 Batch convert multiple images to WebP format. Includes quality adjustment and compression preview.
クロス検索ツール Cross Search Tool
ひとつの情報を複数ソースから検索するための簡易ツール。 A simple tool to search for the same query across multiple services.
HTMLタグ抽出ツール HTML Tag Extractor
HTMLソースからtitleやdescription、OGPなどの各種メタタグを抽出し、CSV・TXTで書き出します。 Extract meta tags (title, description, OGP, etc.) from HTML source and export to CSV/TXT.
Contextual Text Editor
実際のWebページのレイアウトを確認しながら、テキストデータ（CSV）の編集や文言の置換ができるツール。 Edit text data (CSV) and replace wording while checking the actual web page layout.
