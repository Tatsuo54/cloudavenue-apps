HTMLタグ抽出ツールHTML Tag Extractor

使い方How to Use

WebページのHTMLソースコード（テキスト）を貼り付けると、設定したメタタグや見出しなどのテキスト・属性要素を瞬時に抽出します。

  • 設定: 抽出したいタグのON/OFFが可能です。Basic SEO や OGP などのプリセットも用意されています。
  • 2画面比較: 変更前と変更後のHTMLソースを比較するのに便利な2ペイン構成です。Page 2は空のままでも使用できます。
  • 履歴＆書き出し: 「Save to History」で下に履歴データを残すことができ、後からまとめてCSVやTXT形式でダウンロードできます。

Paste the HTML source code to instantly extract semantic texts and attribute elements such as meta tags and headers based on your settings.

  • Settings: You can toggle which tags to extract. Presets like Basic SEO and OGP are available.
  • 2-Pane Comparison: Useful for comparing HTML before and after modifications. "Page 2" can be left blank.
  • History & Export: Save results to the list below and download them later safely as CSV or TXT.
